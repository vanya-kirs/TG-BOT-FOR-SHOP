# Owlreal Bot

Telegram бот для магазина китайских товаров Owlreal.

## Описание

Бот предоставляет следующие возможности:
- Просмотр каталога товаров
- Добавление товаров в корзину
- Оформление заказов
- Административная панель для управления товарами
- Автоматическая публикация постов в канал

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Milashka2007/owlreal_bot.git
cd owlreal_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корневой директории и добавьте необходимые переменные окружения:
```env
TOKEN=your_bot_token
DB_LITE=sqlite+aiosqlite:///your_db_name.db
```

## Структура проекта

- `app.py` - основной файл запуска бота
- `config.py` - конфигурационный файл с настройками
- `handlers/` - обработчики команд и сообщений
- `database/` - работа с базой данных
- `common/` - общие утилиты и тексты
- `kbds/` - клавиатуры и кнопки

## Использование

1. Запустите бота:
```bash
python app.py
```

2. В Telegram найдите бота по имени и начните взаимодействие.

## Административные функции

- Добавление/удаление товаров
- Управление баннерами
- Просмотр корзин пользователей
- Публикация постов в канал

## Технологии

- Python 3.8+
- aiogram 3.x
- SQLAlchemy
- APScheduler
- SQLite
