# Кабинеты и товары

В статическом предпросмотре данные торговли, чеки и уведомления сохраняются в localStorage одного браузера. Демо-поставщик закреплён за s1, переключение поставщиков удалено. Это демонстрация интерфейса, а не граница безопасности: до запуска необходимо перенести торговые операции и файлы на сервер и проверять supplierId по сессии при каждом чтении и изменении. Серверные аккаунты и API брендов реализованы отдельно; они не делают браузерные торговые данные общими между пользователями.

- Поставщик создаёт или изменяет только свои вещи. Цена, базовая цена и скидка сохраняются из существующего товара; новому товару цену назначает магазин. После сохранения статус pending, товар скрыт из каталога и недоступен для добавления в корзину.
- Администратор проверяет форму, назначает цену и публикует товар. Страница /admin/supplier/:id показывает вещи и выплаты выбранного поставщика.
- Долг магазина = начисления по подтверждённым продажам минус записанные выплаты. Выплата не переводит деньги.
- Выплата допускает необязательный чек (PDF/JPEG/PNG/WebP, до 2 МБ). Чек можно добавить или заменить позднее. Выплата и обновление чека дают непрочитанное уведомление; прочтение хранится у записи выплаты. Доставка уведомлений между реальными аккаунтами потребует серверного хранилища.
- Поиск бренда общий для каталога, подсказок, справочника и формы товара: регистр и знаки убираются, кириллица транслитерируется. «адидас» совпадает с Adidas и при ручном создании. Для произношений, отличающихся от транслитерации, нужны aliases, например «Найк». Поиск товаров также проверяет название.
- Бренд создаётся без выбора категорий. Категория вещи выбирается последовательно: раздел, затем подкатегория. Размеры выбираются флажками.

Проверено: поставщик отправляет товар без цены → администратор назначает цену и одобряет; выбор Adidas по кириллической подсказке заполняет строку; демо-выплата уменьшает долг и появляется в уведомлениях поставщика. Автотесты покрывают сохранение цены, запрет чужого товара, фильтрацию pending, поиск вручную добавленного бренда, расчёт долга и изоляцию представлений истории.
