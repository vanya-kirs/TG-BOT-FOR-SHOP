# Адресные подсказки DaData

Интеграция подготовлена, но без личного API-ключа внешний поиск не включён. В новой форме город, улица и дом требуют выбора из подсказок. До настройки сервиса доступны сохранённые адреса и самовывоз.

1. В личном кабинете DaData получить API-ключ для подсказок: https://dadata.ru/api/suggest/address/ . Ключ из примера документации не использовать.
2. На сервере в /opt/vera-prive/.env добавить DADATA_API_KEY со своим значением. Не помещать ключ в dist, исходники или сообщения. Не нужен Secret для стандартизации.
3. После загрузки обновления пересоздать приложение: `docker compose -f /opt/vera-prive/deploy/compose.yaml up -d --force-recreate app`.
4. Войти в магазин, открыть #/checkout и ввести адрес в поле поиска. Выбрать подсказку, проверить заполненные город/улицу/дом. При недоступности сервиса проверить сообщение и возможность использовать сохранённый адрес либо самовывоз.

Запросы идут через сервер, только от вошедшего пользователя, максимум 30 запросов за минуту на пользователя. Ключ не возвращается браузеру. Передаётся введённая строка поиска адреса; отдельные поля имени, телефона и квартиры не отправляются. Ограничение частоты действует в рамках одного процесса. Запросы не журналируются приложением. Для включения проверить условия выбранного аккаунта DaData и отразить сервис в документах оператора. Платная подписка автоматически не оформляется.

Проверки с имитацией ответов сервиса не заменяют проверку рабочего ключа после настройки.
