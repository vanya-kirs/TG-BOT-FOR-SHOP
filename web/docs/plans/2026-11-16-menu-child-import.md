# Меню и перенос детских результатов

- Шапка: кнопка из трёх линий, компактный мобильный логотип и действия в одной строке. Выдвижной dialog слева: поиск, весь каталог, мужское/женское/детское, бренды, скидки, о магазине, контакты. Закрытие крестиком/вне панели/Escape, native modal focus handling, возврат фокуса.
- На главной удалена только ссылка «Новое с биркой» рядом со «Смотреть каталог»; фильтр состояния в каталоге сохранён.
- Восемь завершённых FASHN результатов упакованы в приватную папку deploy/child-test-results (не dist). Импорт создаёт четыре черновика у первого созданного admin (или явно CHILD_TEST_OWNER_ID), по два completed задания. Товаров в продаже не создаёт; повторной генерации нет. Учтено 16 ранее потраченных кредитов, повторный импорт не дублирует задания/расход и не перезаписывает правки черновика.
- Черновикам нужны реальные исходники/обложка для превращения в товар. Результаты видны в версиях спереди/сзади сразу после открытия черновика.
- upload-from-mac.sh выполняет импорт после успешного deploy. Секреты .env не копируются.
- Проверка: 118 тестов, мобильный браузер 390×844: главная, открытие/закрытие меню, переход в детский каталог. Изображения docs/mobile-header-menu.png и docs/mobile-drawer-menu.png.
- Попытка deploy завершилась до передачи файлов: SSH/scp "Connection closed by 192.0.2.10 port 22". Прод в этом запуске не изменён; требуется запуск скрипта пользователем с Mac.
