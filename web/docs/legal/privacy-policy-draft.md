## 3. Как обрабатываются и защищаются данные

Обработка включает сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, предоставление в необходимых случаях, блокирование, удаление, уничтожение и, когда применимо, обезличивание. Используются средства автоматизации; обращения и документы могут также обрабатываться сотрудником вручную.

Оператор обязан обеспечивать конфиденциальность данных и ограничивает доступ к ним лицами, которым он необходим для выполнения их обязанностей. Предоставление доступа само по себе не разрешает использовать данные для посторонних целей.

Для защиты данных применяются разграничение прав пользователей, защита учётных записей, проверка адреса электронной почты, ограничение повторных запросов и защищённое соединение с сайтом. Организационные меры включают контроль доступа, рассмотрение обращений пользователей и порядок действий при нарушении безопасности. Конкретные меры выбираются с учётом угроз и требований законодательства.

Данные не предназначены для открытой публикации. Их распространение неопределённому кругу лиц требует самостоятельного законного основания; согласие на ведение кабинета такого разрешения не даёт.

## 4. Кому могут предоставляться данные

Для размещения сайта и работы доменной почты используются услуги REG.RU. Объём доступа исполнителя определяется договором, используемой услугой и необходимостью обеспечить её работу.

При выборе внешнего входа задействуется соответствующий сервис — Яндекс или Google, если он доступен на сайте. Пользователь может выбрать вход по email вместо внешнего сервиса. Передача сведений при таком входе ограничивается необходимым для авторизации и предусмотренным выбранным способом входа объёмом.

При исполнении заказа данные могут предоставляться согласованной с покупателем службе доставки: Достависта, СДЭК, Почта России либо другому выбранному перевозчику. Передаются только сведения, необходимые для конкретной доставки. Наличие названия службы в этой Политике не означает передачу ей данных всех посетителей сайта.

Получатели, обрабатывающие данные по поручению Оператора, привлекаются на условиях, соответствующих требованиям закона. Государственным органам данные предоставляются в случаях и порядке, установленных законом.

При открытии размещённых на внешних ресурсах изображений браузер обращается к соответствующему ресурсу, включая images.unsplash.com, и передаёт необходимые для соединения технические сведения. Переход на сторонний сайт регулируется также документами его владельца. Отсутствие рекламных счётчиков не означает полного отсутствия внешних соединений.

Использование иностранных сервисов требует отдельной оценки трансграничной передачи. Настоящая Политика не является согласием на неограниченную передачу данных за рубеж и не заменяет предусмотренные законом уведомления. При обработке данных граждан РФ Оператор обязан соблюдать требования к расположению баз данных и ограничения использования зарубежных баз.

Загрузка узнаваемых фотографий людей в сервис обработки изображений не покрывается согласием на личный кабинет. До такой обработки должны быть определены самостоятельное основание, получатель и условия передачи.

## 6. Сроки хранения и прекращение обработки

Сведения хранятся не дольше, чем этого требуют цели обработки, если иной срок не установлен законом или применимым договором. Для проекта согласованы следующие правила:

| Категория | Срок или событие прекращения хранения |
| --- | --- |
| Данные личного кабинета, избранное и сохранённые адреса | До удаления кабинета или прекращения соответствующей функции по обращению пользователя; после отзыва согласия — по правилам закона с учётом иных сохраняющихся оснований |
| Обычная переписка, не относящаяся к заказам, претензиям или обязательным документам | До 1 года после закрытия вопроса; более раннее удаление — при прекращении основания обработки |
| Технические журналы безопасности | До 90 дней; связанные с конкретным расследованием записи выделяются и хранятся только на самостоятельном законном основании |
| Резервные копии | Цикл хранения до 30 дней; при восстановлении повторно применяются ранее поступившие требования об удалении |
| Заказы, претензии, договоры и обязательные учётные документы | Срок определяется видом документа и применимым требованием закона; удаление кабинета не отменяет обязательного хранения. До публикации должна быть утверждена отдельная номенклатура сроков |
| Неподтверждённые аккаунты, незавершённые заявки, записи одноразовых кодов | Незавершённые регистрации по email без подтверждения почты, активных сеансов, внешних способов входа, заказов и служебной роли — 7 дней. Просроченные коды и сеансы удаляются при ближайшей ежечасной очистке. Срок хранения незавершённых заказов определяется отдельно; автоматическое удаление истории заказов не выполняется |

По достижении цели или после отзыва согласия данные, для которых больше нет основания обработки, уничтожаются в предусмотренные законом сроки. В случаях, охватываемых частями 4 и 5 статьи 21 Закона № 152-ФЗ, общий срок составляет до 30 дней с учётом установленных законом исключений. Для отдельных требований закон устанавливает иные сроки.

Удаление выполняется из действующих систем и учитывается при обращении с резервными копиями. Если закон требует продолжить хранение части документов, Оператор сохраняет только необходимый объём данных и ограничивает их дальнейшее использование соответствующей целью.

## 7. Права пользователя

Пользователь вправе получать предусмотренные законом сведения об обработке своих данных, требовать уточнения, блокирования или уничтожения данных в установленных случаях, отозвать согласие, а также обратиться в Роскомнадзор или суд.

Для обращения напишите на info@shop.example.com и укажите суть требования и сведения, позволяющие найти ваш аккаунт или заказ. Для проверки полномочий Оператор может запросить необходимые дополнительные сведения с соблюдением принципа достаточности. Пароль и код входа для этого не требуются.

Ответы и действия по обращениям выполняются в сроки, предусмотренные законом для соответствующего требования. Отзыв согласия не прекращает обработку, для которой сохраняется иное законное основание. Удаление cookie в браузере не является запросом на удаление аккаунта или данных на сервере.

## 8. Изменения Политики

Актуальная редакция размещается в свободном доступе на сайте. Ссылки на неё должны быть доступны при сборе персональных данных. В документе указывается дата начала действия утверждённой редакции.

Обновление текста Политики не считается получением согласия на новую цель обработки. Когда требуется отдельное согласие, оно запрашивается отдельно.

При оформлении заказа собираются имя получателя, телефон, выбранный способ доставки и адрес (город, улица, дом, корпус, подъезд, этаж, квартира, домофон). Для самовывоза адрес покупателя не запрашивается. Адрес можно по выбору сохранить в личном кабинете под названием. В заказе сохраняется самостоятельная копия данных доставки; изменение адресной книги её не меняет. Автоматическая передача службам доставки пока не подключена.

Адресные подсказки: подготовлено подключение DaData. При включённом сервисе введённая строка поиска адреса передаётся DaData через сервер магазина для подбора вариантов. Отдельные поля имени, телефона, квартиры, подъезда и этажа в запрос подсказок не включаются. Адрес можно ввести вручную. До включения требуется настроить личный API-ключ и проверить сведения об исполнителе по договору.
