# Vera Privé — первая веб-версия

Самостоятельный интерактивный прототип в согласованном светлом стиле. Исходники и готовая статическая сборка находятся в `dist/`. Зависимости и сборщик не нужны.

Запуск из корня репозитория: `python3 -m http.server 4173 --bind 127.0.0.1 --directory web/dist`.
Открыть http://127.0.0.1:4173. Проверки: `node --test web/tests/*.test.mjs`.

Каталог, поиск, категории, карточка товара, избранное, корзина, демо-заказ, история заказов, добавление и редактирование товаров, подтверждение продажи, выплаты поставщику. Вся информация сохраняется только в localStorage данного браузера. Переключение демонстрационных ролей находится в футере. Это НЕ авторизация. Не вводите персональные или рабочие данные.

Деньги хранятся в целых копейках. Комиссия 15% начисляется при подтверждении продажи; 85% — поставщику. Заявка не списывает остаток. Повторное подтверждение запрещено. Выплата не может превышать начисленный долг. Эти правила соответствуют текущему боту, но демо не подключено к его БД.

## До запуска настоящего магазина

- Создать серверный API поверх PostgreSQL и существующих моделей. Не синхронизировать localStorage с рабочими таблицами.
- Серверная авторизация, отдельные роли и привязка пользователя к поставщику. Фильтрация и расчёты должны выполняться на сервере, с блокировками транзакций.
- Добавить варианты товаров (размер/цвет), фотографии в объектном хранилище, контакты и адреса веб-покупателя. Нынешний User требует Telegram user_id; нужна отдельная согласованная миграция.
- Подключить выбранного платёжного провайдера, проверку подписей webhook, идемпотентность, возвраты, правила доставки. Пока платёжных реквизитов и списаний нет.
- Заменить демонстрационные фотографии/товары, контакты, добавить утверждённые условия магазина и готовый логотип. Изображения сейчас загружаются с Unsplash.

Оригинал логотипа пользователя: `dist/assets/vera-prive-logo.jpg`. В шапке и футере CSS показывает монограмму рядом с текстовым названием; полный оригинал выводится на странице «О магазине». Растровый файл не изменён. Цвета вынесены в CSS-переменные.

ЛК покупателя: `#/account`, разделы `overview`, `orders`, `favorites`, `profile`, `addresses`. Профиль и адреса доступны для тестирования с вымышленными данными; реальные регистрация, доставка и обработка персональных данных не подключены. `dist/account.js` содержит представление кабинета и валидацию профиля/адресов. Переходы между разделами плавно прокручивают к содержимому; системный `prefers-reduced-motion` отключает анимацию. Проверки кабинета: `node --test web/tests/account.test.mjs` из корня проекта.

## Каталог и кабинеты продавцов

`dist/merchandising.js`: фильтры цены/размера/цвета/скидок, галереи, скидки, месячные графики и контакты. Фильтр цены учитывает скидку. Скидка 0–90% применяется к исходной цене, не накапливается; оформленные заказы сохраняют снимок цены, комиссия рассчитывается от фактической продажи. Администратор меняет скидки в таблице товаров, поставщик — в своих товарах.

Новые и редактируемые объявления требуют 2–8 уникальных фотографий: HTTPS-ссылки по одной на строку либо загрузка JPEG/PNG/WebP до 1 МБ каждый. Первое фото — обложка. В карточке каталога работают свайп, стрелки и клавиши ←/→ при фокусе на галерее; название и «Подробнее» открывают товар. У старых демо-товаров сохранена единственная исходная фотография: дополнительные ракурсы не выдумываются, их нужно добавить в форме. Большие галереи могут превысить квоту localStorage; приложение показывает ошибку и откатывает изменение.

Графики в обзоре администратора и поставщика, а также в выплатах поставщика: 3/6/12 месяцев, продажи, начисления, выплаты и таблица точных сумм. Месяцы по Москве, дата продажи — `confirmedAt`, для старых записей — `date`.

Социальные площадки в футере: Telegram-канал, Telegram-бот, WhatsApp, Авито, OSKELLY. Ссылки пока `null` в `socials` и показаны как «Ссылка скоро»; реальные адреса добавляются туда после получения.

Адрес доставки: город, улица, дом, корпус, подъезд, этаж, квартира. Индекс больше не используется. Город, улица и дом обязательны, остальные поля допускают отсутствие (частный дом и т. п.). Старые адреса сохраняются, при редактировании нужно отдельно заполнить дом.

Отдельное избранное доступно по `#/favorites` и через сердце в закреплённой шапке. При добавлении сердечко перелетает к кнопке; анимация отключена при `prefers-reduced-motion`. Избранное в ЛК и отдельном разделе используют одну коллекцию.

## Проверка галереи

Объявление `vera-test-coat-v1` («Пальто “Тихое утро” · тестовое») добавляется один раз в новый или существующий демо-каталог. Три вида одной модели сгенерированы imagegen: спереди, сзади, деталь ткани. Исходный триптих — `dist/assets/test-coat.png`; CSS показывает каждый его кадр отдельно, без изменения растрового файла. Это демонстрационный, не продающийся товар. Краткий промпт: same beige wool belted coat, equal front/back/lapel-detail panels, ivory studio, no text.

Галерея поддерживает мышь (перетаскивание), сенсорный свайп, горизонтальный трекпад, стрелки и клавиатуру; вертикальный скролл страницы не перехватывается. Плашка «Подробнее» удалена, переход — по названию. Лайк обновляет только элементы управления, без `render()`, сохраняет страницу и положение галереи. Полёт сердца — 1450 мс. При удалении из открытого избранного карточка временно остаётся с подписью об удалении, чтобы не сдвигать страницу; повторный лайк возвращает её.
